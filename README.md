# CodeAlpha_IrisFlowerClassification

Task 1 of the CodeAlpha Data Science internship: classify Iris flowers
(*setosa*, *versicolor*, *virginica*) from sepal/petal measurements, with a
simple interactive web UI to try live predictions.

## What's inside

| File | Purpose |
|---|---|
| `Iris.csv` | Dataset (150 samples, 4 features, 3 species) |
| `train_model.py` | EDA, model comparison, hyperparameter tuning, saves the trained model |
| `app.py` | FastAPI backend — serves the model + the UI |
| `static/index.html` | Single-page UI (sliders → live prediction) |
| `iris_model.pkl`, `label_encoder.pkl` | Trained artifacts (generated by `train_model.py`) |
| `model_metadata.json` | Accuracy figures & best hyperparameters (generated by `train_model.py`) |

## Approach

1. **Preprocessing** — dropped the `Id` column, label-encoded the species,
   scaled the 4 numeric features with `StandardScaler`.
2. **Model comparison** — Logistic Regression, KNN, Decision Tree,
   Random Forest, and SVM (RBF) were compared with 5-fold stratified
   cross-validation on the training split.
3. **Tuning** — SVM came out on top, so `GridSearchCV` searched over
   kernel (`linear`/`rbf`/`poly`), `C`, and `gamma`.
4. **Evaluation** — reported both a 10-fold CV accuracy on the full
   dataset (the more reliable number on a small dataset like this) and
   accuracy on a held-out 20% test split.

### Results

- **10-fold CV accuracy (full dataset): ~95–97%**
- Held-out test accuracy: ~93%
- Best model: **SVM**, linear kernel, tuned via `GridSearchCV`

(Exact numbers are written to `model_metadata.json` each time you retrain,
and are shown live in the UI itself.)

## Running it locally

```bash
pip install -r requirements.txt      # or: pip install fastapi uvicorn scikit-learn pandas numpy joblib

# 1. Train the model (writes iris_model.pkl, label_encoder.pkl, model_metadata.json)
python train_model.py

# 2. Start the API + UI
uvicorn app:app --reload

# 3. Open the UI
# http://127.0.0.1:8000
```

Move sliders for sepal length/width and petal length/width — the diagram
and the predicted species (with confidence per class) update live, calling
the `/api/predict` endpoint of the FastAPI backend.

## API

`POST /api/predict`
```json
{ "sepal_length": 5.1, "sepal_width": 3.5, "petal_length": 1.4, "petal_width": 0.2 }
```
→
```json
{
  "species": "Iris-setosa",
  "common_name": "Setosa",
  "confidence": 97.98,
  "probabilities": { "Iris-setosa": 97.98, "Iris-versicolor": 1.16, "Iris-virginica": 0.86 }
}
```

`GET /api/health` — returns model metadata (accuracy, best hyperparameters).
